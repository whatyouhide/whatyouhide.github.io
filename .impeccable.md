## Design Context

### Users

The main users are technical readers who come to read long essays about software, systems, and Elixir. Other visitors scan Andrea's profile, books, talks, teaching work, and travel notes.

### Brand Personality

Clear, exact, and personal. The site should feel like the work of one experienced engineer and writer, not a product site or a theme demo.

### Aesthetic Direction

Keep the dark theme as a restrained CRT terminal. Make the light theme a neutral white editorial publication with confident scale and asymmetric composition. Use strong type contrast, sharp rules, plain surfaces, and generous space. Keep green as a focused link and print accent. Use a full-color portrait. Do not use cream paper tones, decorative gradients, heavy shadows, or generic card grids.

### Design Principles

1. Put reading first. Long essays need clear type, a useful line length, and calm spacing.
2. Let each color scheme have its own visual language while both keep the same content and structure.
3. Use EB Garamond for editorial titles, IBM Plex Sans for reading, and IBM Plex Mono only for code and data.
4. Keep light mode neutral and close to white. Use color only for links and clear status.
5. Use CSS media queries for the theme split. Do not add JavaScript for styling.
6. Make the sidebar the main editorial focal point through scale, image crop, and compact credit lines.
